# AI Usage Disclosure

This project was developed with the assistance of AI coding agents.

## AI Assistance

AI coding agents (including OpenCode, Codex, and DeepSeek) were used to:

- Generate and review backend C# code (ASP.NET Core Web API, Entity Framework Core, Npgsql)
- Generate and review frontend TypeScript/React code (Vite, TanStack Query, Axios, React Hook Form, Zod, Tailwind CSS)
- Generate Docker Compose deployment files (docker-compose.yml, Dockerfiles, nginx.conf)
- Generate documentation (README.md, ASSUMPTIONS.md, this file)
- Review and refine concurrency, migration, and persistence logic

## Human Involvement

The project owner provided:

- Requirements and technology stack decisions
- Manual frontend testing (reservation creation, confirmation, cancellation, student identity switching)
- Test baseline verification (139 backend tests, 20 frontend tests)
- Git operations (staging, committing, pushing)
- Local development environment setup (PostgreSQL 18, .NET SDK 10, Node.js 22)
- Review and approval of implementation direction

## Limitations

AI-generated code was inspected, tested, and validated against the repository before inclusion.
All AI contributions were reviewed for correctness, security, and alignment with the assignment requirements.
No confidential recruitment materials, recruiter emails, or real credentials were included in the repository.
